Browser

Консольный браузер для Windows. Полноценный веб прямо в терминале — без окон, без GUI, без зависимостей. Один exe-файл.

C:\> Browser.exe # и вводите адрес или запрос
Скачать для Windows

Все релизы на GitHub

Возможности

Всё, что нужно для повседневного серфинга — минус графическая оболочка.

Поиск и навигация

DuckDuckGo → Bing → Google, история, закладки, вкладки до 12 штук, восстановление сессии.

Загрузки

До 3 файлов параллельно, очередь, докачка после обрыва, проверка SHA-256.

RSS и reader-режим

Ленты Atom/RSS как читаемый список новостей, чистый текст статей без мусора.

Изображения

Truecolor-просмотр картинок прямо в консоли, скачивание в один клик.

Формы

GET/POST-формы: текст, пароли, чекбоксы, списки — редактирование и отправка.

Скорость

WinHTTP, gzip, keep-alive, кэш с ETag — повторные страницы открываются мгновенно.

Headless Edge

JS-сайты автоматически перерисовываются через установленный Edge — YouTube, Gmail и SPA работают.

Синхронизация

Опционально: история и закладки через GitHub Gist между компьютерами.

Командная строка

Нажмите ;, : или F2 — внизу откроется строка команд с автодополнением: back, stats, tabs, md…

Reader-режим и темы

m — чистый текст статьи без меню и рекламы. Светлая/тёмная тема + свои темы из data/themes/*.json.

Экспорт и бэкапы

session — вкладки+история+закладки одним файлом, md — страница в Markdown, ежедневные бэкапы data/.

Офлайн и скорость

Кэш до 500 МБ с авто-эвикцией, офлайн-индикатор, префетч ссылок, прогресс загрузки в байтах и %.

Мышь и WebView2

Полная работа мышью: ссылки, вкладки, меню ⚙ Настройки. Команда web открывает страницу в окне Chromium.

Управление

Клавиатура в стиле браузерных хоткеев. Мышь тоже работает — наведение, клик, колесо.

Быстрый старт

Скачайте Browser.exeОдин файл, ~2.5 МБ. Распакуйте в любую папку.
Запустите в терминалеWindows Terminal, PowerShell или cmd — двойной клик по ярлыку тоже сработает.
Введите адрес или запросНапример wikipedia.org или погода москва — нажмите Enter.
Пользуйтесьj/k — по ссылкам, Enter — открыть, o — новый адрес.
