## Что это

Browser — браузер, который живёт **внутри консоли Windows**. Вы вводите адрес или поисковый запрос — и получаете читаемую страницу: заголовки, текст, таблицы, кликабельные ссылки, картинки в truecolor. Никаких окон, лаунчеров и «тормозов» — только терминал и скорость.

│ ‹ › ⟳  │  example.com/article-title              │ 🔖 ⬇ │
├──────────────────────────────────────────────────────────┤

## Возможности

| | |
|---|---|
| 🔎 **Поиск** | DuckDuckGo → Bing → Google с автоматическими fallback'ами |
| 🗂 **Вкладки** | До 12 штук, `Ctrl+T/W/Tab/1-9`, восстановление сессии |
| 📥 **Загрузки** | До 3 параллельно, очередь, докачка (`Range`), SHA-256 |
| 📰 **RSS/Atom** | Ленты рендерятся как читаемый список новостей |
| 🖼 **Картинки** | Truecolor-просмотр в консоли (WIC + ANSI), скачивание |
| 📝 **Формы** | GET/POST: текст, пароль, чекбокс, radio, select, submit |
| 📄 **Reader-режим** | Статьи без навигации, рекламы и cookie-баннеров |
| ⚡ **Скорость** | WinHTTP, gzip, keep-alive, кэш с ETag/Last-Modified |
| 🌐 **IDN** | Кириллические домены (`пример.рф`) из коробки |
| 🧩 **Headless Edge** | JS-сайты перерисовываются через Edge автоматически |
| 🔄 **Синхронизация** | Опционально: история/закладки через GitHub Gist (`gh`) |
| 🎨 **Темы** | Тёмная/светлая (`Ctrl+Shift+L`) |

## Управление

**Клавиатура** — основной способ, мышь работает тоже (наведение, клик, колесо).

| Клавиши | Действие |
|---|---|
| `j` `k` / `↑` `↓` | Выбор ссылки или поля |
| `Enter` | Открыть / отправить форму |
| `o` | Адресная строка с автодополнением |
| `b` `f` `r` | Назад / Вперёд / Обновить |
| `Ctrl+T` `Ctrl+W` | Новая / закрыть вкладку |
| `Ctrl+Tab` `Ctrl+1–9` | Переключение вкладок |
| `Ctrl+J` | Загрузки: открыть, `v` — sha256, `x` — отмена |
| `Ctrl+H` `Ctrl+D` `Ctrl+B` | История / закладка / закладки |
| `Ctrl+S` | Сохранить страницу |
| `Ctrl+C` `Ctrl+V` | Копировать ссылку / вставить URL |
| `d` на ссылке | Скачать файл |
| `Ctrl+F` `/` | Поиск по странице |
| `Esc` | Отмена → назад → выход |

Полный список команд — `help` внутри браузера.

## Быстрый старт

1. Скачайте `Browser-*.exe` из [Releases](../../releases) — один файл, ~2.5 МБ.
2. Запустите в любом терминале Windows (Windows Terminal, PowerShell, cmd).
3. Введите адрес (`wikipedia.org`) или запрос (`погода москва`) → `Enter`.

Данные (история, кэш, загрузки) хранятся **рядом с exe** — можно носить на флешке.

## Требования

- Windows 10/11, x64
- Ничего устанавливать не нужно — один exe
- Опционально: [GitHub CLI](https://cli.github.com/) для синхронизации, Edge — для JS-сайтов

## Ограничения

Это консольный браузер, а не Chrome:

- CSS-вёрстка и JavaScript не исполняются (JS-сайты — через headless Edge)
- Рендеринг текстовый: структура сохраняется, пиксельной вёрстки нет
- Только HTTP/HTTPS; формы без JS и `multipart/form-data`

## Разработка

Исходники пока не публикуются. Проверено: MSVC + CMake 3.24+, C++20, ~170 автотестов.
