## Что это

Browser — браузер, который живёт **внутри консоли Windows**. Вы вводите адрес или поисковый запрос — и получаете читаемую страницу: заголовки, текст, таблицы, кликабельные ссылки, картинки в truecolor. Никаких окон, лаунчеров и «тормозов» — только терминал и скорость.

```
┌──────────────────────────────────────────────────────────┐
│ ‹ › ⟳  │  example.com/article-title              │ 🔖 ⬇ │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  ■ Заголовок статьи                                      │
│                                                          │
│  Первый абзац текста статьи. Ссылки [1] кликабельны,     │
│  таблицы выровнены по колонкам, картинки можно смотреть  │
│  прямо в консоли.                                        │
│                                                          │
│  • Список                                                       │
│  • Элементов                                                      │
│                                                          │
├──────────────────────────────────────────────────────────┤
│ 🔍 Найти…   ⇩ 0.0 МБ   Ctrl+J загрузки   help — команды  │
└──────────────────────────────────────────────────────────┘
```

## Возможности

| | |
|---|---|
| 🔎 **Поиск** | DuckDuckGo → Bing → Google с автоматическими fallback'ами |
| 🗂 **Вкладки** | До 12 штук, `Ctrl+T/W/Tab/1-9`, pin/имена/перестановка, восстановление сессии и именованные снапшоты (`sessions`/`restore`) |
| 📥 **Загрузки** | До 3 параллельно, очередь, докачка (`Range`), SHA-256 |
| 📰 **RSS/Atom** | Ленты рендерятся как читаемый список новостей |
| 🖼 **Картинки** | Truecolor-просмотр в консоли (WIC + ANSI), скачивание |
| 📝 **Формы** | GET/POST: текст, пароль, чекбокс, radio, select, submit |
| 📄 **Reader-режим** | Статьи без навигации, рекламы и cookie-баннеров |
| ⚡ **Скорость** | WinHTTP, gzip, keep-alive, кэш с ETag/Last-Modified |
| 🌐 **IDN** | Кириллические домены (`пример.рф`) из коробки |
| 🧩 **Headless Edge** | JS-сайты перерисовываются через Edge автоматически |
| 🔄 **Синхронизация** | Опционально: история/закладки через GitHub Gist (`gh`) |
| 🎨 **Темы и вид** | Именованные темы (`theme <имя>`, `theme save`), zoom текста, полноэкранный режим, отключение картинок/автоподгрузки/строки состояния |
| ⌘ **Палитра команд** | `Ctrl+K` — fuzzy-поиск по командам, истории, закладкам и вкладкам |
| ⚙ **Страница настроек** | `browser://settings` — все переключатели в одном месте |
| 📡 **RSS-агрегатор** | `feed add <url>` + `browser://feeds` — ленты в одном списке |
| 🔄 **Автообновление** | `update` / `update apply` — проверка и установка нового релиза |
| 📚 **Очередь чтения** | `queue add/next/del` + `browser://queue` — «прочитать позже» |
| 🗞 **RSS-дайджест** | `digest` — всё новое по всем лентам за сутки на одной странице |
| 🧩 **Макросы** | `data/macros.txt`: `имя = команда ; команда` → `macro <имя>` |
| 🛠 **Правила сайтов** | `data/rules/*.txt`: `url → hide/replace/theme` без JS-движка |
| 🎨 **Темы по сайтам** | `data/sites/<хост>.theme` — своя тема для конкретного сайта |
| 📖 **Офлайн-википедия** | `wsave <статья>` → `wiki/`, `woffline`/`wiki` — без сети |
| 📦 **Экспорт в Markdown** | `export-md <дни>` — статьи из истории → `saved/articles/` |
| 🪟 **Интеграция с Windows** | `register-protocol`, `fileassoc`, toast-уведомления о загрузках |
| 🔬 **DevTools-lite** | `browser://headers`, `browser://cookies`, `netlog` — куки и лог сети |
| ☁ **Синхронизация+** | Gist: история/закладки/**заметки/ленты/очередь** с merge, `browser://sync` diff |

## Управление

**Клавиатура** — основной способ, мышь работает тоже (наведение, клик, колесо).

| Клавиши | Действие |
|---|---|
| `j` `k` / `↑` `↓` | Выбор ссылки или поля |
| `Enter` | Открыть / отправить форму |
| `o` | Адресная строка с автодополнением |
| `b` `f` `r` | Назад / Вперёд / Обновить |
| `Ctrl+T` `Ctrl+W` | Новая / закрыть вкладку |
| `Ctrl+Tab` `Ctrl+1–9` | Переключение вкладок |
| `Ctrl+J` | Загрузки: открыть, `v` — sha256, `x` — отмена |
| `Ctrl+H` `Ctrl+D` `Ctrl+B` | История / закладка / закладки |
| `Ctrl+S` | Сохранить страницу |
| `Ctrl+C` `Ctrl+V` | Копировать ссылку / вставить URL |
| `d` на ссылке | Скачать файл |
| `Ctrl+F` `/` | Поиск по странице |
| `Ctrl+Enter` в адресной строке | Открыть в новой вкладке |
| `Ctrl+K` | Командная палитра: команды, история, закладки, вкладки |
| `F11` | Полный экран |
| `Esc` | Отмена → назад → выход |

Боковые кнопки мыши: X1 — назад, X2 — вперёд.

Полный список команд — `help` внутри браузера (~110 команд: `tabname`, `pin`, `engine`, `offline`, `zoom`, `theme`, `snapshot`, `sessions`, `lucky`, `copy`, `find`, `feed`, `settings`, `update apply`, `queue`, `macro`, `wsave`, `digest`, `export-md`, `headers`, `netlog`, `rules`, `syncpage`, `register-protocol`, `fileassoc`…).

### Экосистема: файлы данных

Рядом с `data/` можно класть свои правила и макросы (примеры — в `examples/`):

- `data/macros.txt` — `morning = home ; feeds ; digest`
- `data/rules.txt` или `data/rules/<сайт>.txt` — `<часть-url>⇥hide <текст>` / `⇥replace <от> => <до>` / `⇥theme <имя>`
- `data/sites/<хост>.theme` — файл с именем темы, напр. `habr.com.theme` → `Тёмная`
- `data/queue.txt`, `data/wiki/`, `data/cookies.txt`, `data/netlog.txt` — создаются сами

`theme pull <имя>` качает темы из галереи (`themes/*.json` в этом репо → сайт).

## Быстрый старт

1. Скачайте `Browser-*.exe` из [Releases](../../releases) — один файл, ~2.9 МБ.
2. Запустите в любом терминале Windows (Windows Terminal, PowerShell, cmd).
3. Введите адрес (`wikipedia.org`) или запрос (`погода москва`) → `Enter`.

Данные (история, кэш, загрузки) хранятся **рядом с exe** — можно носить на флешке.

## Требования

- Windows 10/11, x64
- Ничего устанавливать не нужно — один exe
- Опционально: [GitHub CLI](https://cli.github.com/) для синхронизации, Edge — для JS-сайтов

## Ограничения

Это консольный браузер, а не Chrome:

- CSS-вёрстка и JavaScript не исполняются (JS-сайты — через headless Edge)
- Рендеринг текстовый: структура сохраняется, пиксельной вёрстки нет
- Только HTTP/HTTPS; формы без JS и `multipart/form-data`

## Разработка

Исходники — в этом репозитории (ветка `main`, папки `src/`, `tools/`, `tests/`).
Готовый exe — в [Releases](../../releases) и в корне репозитория.

**Сборка** (Windows, MSVC + CMake 3.24+, C++20; Lexbor скачается автоматически):

```powershell
cmake -S . -B build
cmake --build build --config Release --parallel
# готовый exe: build/Release/Browser.exe
```

**Структура:** `src/` — код браузера · `tools/harness.cpp` — тестовый харнесс
(прикрепляется к живому окну и «нажимает» клавиши/мышь) · `tests/` —
механики (`mechanics.txt`) и фикстуры · `assets/` — иконка и ресурсы ·
`index.html` — этот сайт (GitHub Pages).

Проверено: ~180 автотестов (`build/Release/browser_tests.exe`) и 21 живая
проверка механик через харнесс.
