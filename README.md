# Browser

Консольный браузер для Windows 10/11 на C++20. Без GUI и WebView2 — работает прямо в терминале: поиск, страницы, вкладки, история, закладки, загрузки, RSS, картинки.

## Скачать

Готовый `Browser.exe` — в [Releases](https://github.com/fanxcz/browser/releases):

- Windows 10/11, x64
- Один файл, ~2.5 МБ, ничего устанавливать не нужно
- Данные (история, кэш, загрузки) хранятся рядом с exe

## Возможности

- Поиск (DuckDuckGo → Bing → Google) и прямые адреса
- Вкладки `Ctrl+T/W`, история `Ctrl+H`, закладки `Ctrl+D/B`
- Загрузки `Ctrl+J`: параллельно до 3 файлов, докачка, SHA-256
- RSS/Atom-ленты, таблицы, reader-режим
- Просмотр картинок в консоли, `Ctrl+S` — сохранение страниц
- JS-сайты: автоматический fallback через headless Edge

## Управление

Клавиатура в стиле браузерных хоткеев (`j/k` по ссылкам, `Enter` — открыть,
`o` — адресная строка, `d` — скачать, `/` — поиск по странице), мышь тоже работает.
Полный список — в `help` внутри браузера.
